# Workspace Memory

## Workspace Purpose

- This folder is both the active filesystem workspace and an Obsidian vault for Minecraft work.
- The vault contains several independent projects; `bonded_companions` is currently the main project.

## Durable Obsidian Decisions

- Existing project files must not be moved or edited merely to create graph relationships.
- Obsidian relationships live in the additive `_graph` layer.
- Relationship notes point to original files so backlinks work without modifying those originals.
- The global graph provides discovery; the Canvas provides stable layout and labeled relationship meaning.
- No community plugin is required for the graph system.
- The Bonded Companions entity graph is generated from `_graph/tools/build-entity-graph.ps1`; generated entity notes should not be edited manually.
- The entity layer separates specified behavior, registered data, prototype behavior, and P0-pending behavior so planned abilities are not presented as complete.

## Protected Content

- Files under `bonded_companions` remain governed by that project's own `AGENTS.md` and `MEMORY.md`.
- The `_graph` layer is descriptive and must not override project source-of-truth documents.

## Maintenance Notes

- When a new top-level project gains a Markdown entry document, add it to `_graph/MC 项目总览.md`.
- When the authority of a project document changes, update the relevant relationship note and Canvas edge label.
- Never store secrets in this file or in graph metadata.
- The entity graph currently covers 13 creatures, 37 item/integration nodes, 31 custom enchantments, and 7 shared systems.
- `bonded_companions/PRD.md`, `RECIPES.md`, current resources, and implementation status now agree on separate Snow Golem and Iron Golem reinforcement lines. Four old shared IDs remain hidden migration entries only.
